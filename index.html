1. 데이터

데이터는 숫자나 문자, 이미지, 소리, 동영상 등 다양한 형태로 표현되는 사실이나 기록

2. 데이터 수집 방법의 변화

일상생활 데이터 필요한 데이터를 주변에서 직접 모으고, 필요할 때 사용할 수 있도록 별도로 보관함.
인터넷상 데이터 스마트폰을 이용하여 실시간 정보를 모으고, 원할 때 언제든지 꺼내 볼 수 있음.
